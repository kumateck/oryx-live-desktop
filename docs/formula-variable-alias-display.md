# Available-variable aliases

The Universal formula editor groups supplied standard and sample input keys into one dropdown per input group. The trigger shows its input group and alias count; it does not retain a selected alias. Each option shows its exact token, description and existing value or auto indicator. Selecting it calls the existing insert-at-cursor action. Statistics and unrelated variables remain separate; numbered samples remain distinct.

Display grouping recognizes Weight, Conc, Absorbance, PeakAreas and TitreValue suffixes only when the existing editor provides those keys. It never creates tokens or makes independent values equivalent. Evaluators, alias resolution, persisted formula configuration, worksheet inputs, units and conversion rules are unchanged. Older formulas retain their existing meaning.

The formula editor's existing access and save permissions continue to apply. This local display interaction adds no endpoint or permission grant.

Reserved-key descriptions also default consistently in Test Formula, analyst inputs, saved raw-data worksheets, recorded-input previews, printing and formula review. The display resolver covers standard, sample and numbered-sample keys, uses configured weight/concentration units when available, and preserves explicit custom labels. It never changes serialized evidence, formula definitions, calculation bindings or approved certificate snapshots.
